## 4. YÊU CẦU MẪU BÁO CÁO CỦA TRƯỜNG

Trường có thể có quy định riêng về:
- [ ] Trang bìa (mẫu Word cụ thể do trường cung cấp)
- [ ] Font chữ bắt buộc (Times New Roman 13 — đã áp dụng)
- [ ] Khoảng cách lề theo quy định trường
- [ ] Số trang tối thiểu/tối đa
- [ ] Yêu cầu về lời cam đoan (mẫu chuẩn)
- [ ] Yêu cầu về nhận xét giảng viên hướng dẫn
- [ ] Yêu cầu về nhận xét giảng viên phản biện
- [ ] Yêu cầu đóng bìa (màu bìa, cách đóng)
- [ ] Số bản nộp
- [ ] File điện tử nộp qua hệ thống nào

**Sinh viên cần liên hệ khoa/phòng đào tạo để xác nhận các yêu cầu trên.**

## 6. THÔNG TIN KHÔNG ĐƯA VÀO BÁO CÁO

Các thông tin sau **TUYỆT ĐỐI KHÔNG** đưa vào báo cáo:
- API key thực tế (GEMINI_API_KEY, MOCKAPI_URL thực tế, v.v.)
- Mật khẩu database
- Token xác thực thực tế
- Thông tin tài khoản cá nhân
